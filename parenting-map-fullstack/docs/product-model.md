# 育儿百科产品模型

本文档是后续产品设计、原型和开发的共同依据。当前产品方向已经收敛为：**知识百科 + 行动计划**。

## 产品定位

**育儿百科** 是面向 0-7 岁孩子家长的知识和行动辅助 App。

核心不是家庭相册、成长记录、复杂测评或社区，而是：

- 遇到问题时，能快速查到可信百科
- 查完之后，能进入可执行的行动计划
- 通过持续计划，辅助家长帮助孩子健康成长
- 宝宝档案只做轻量个性化和健康节点提醒

一句话：**查问题，跟计划，陪孩子健康成长。**

## 明确不做

| 内容 | MVP 处理 |
|---|---|
| 家庭相册 | 不做 |
| 照片/视频成长记录 | 不做 |
| 排便、睡眠、喂养等复杂记录 | 不做独立系统 |
| 独立测评系统 | 不做 |
| 亲友互动/家庭协同 | 不做 MVP |
| 妈妈圈/同城社区 | 不做 MVP |
| 商城导购 | 不作为主路径 |

## 保留什么记录

记录不再是独立大模块，而是并入 **宝宝档案**。

只保留：

- 宝宝基础信息
- 当前月龄
- 过敏史/重点关注问题
- 打过几次疫苗
- 做过几次儿保体检
- 下次疫苗/儿保健康节点

不做：

- 每天排便记录
- 每天睡眠记录
- 每顿喂养记录
- 用药流水账
- 成长照片流

## 五维需求分析

| 角色 | 场景 | 任务 | 触点 | 结果/成功标准 |
|---|---|---|---|---|
| 新手妈妈/爸爸 | 发烧、咳嗽、腹泻、辅食、夜醒、疫苗前后 | 快速查问题、判断下一步、开启相关计划 | 手机 App、搜索、语音、夜间模式、提醒 | 30 秒内知道下一步，能继续执行 |
| 学习型家长 | 辅食添加、睡眠调整、戒夜奶、如厕、语言启蒙、入园准备 | 选择目标、开启计划、执行每日任务、调整方法 | 计划日历、每日任务卡、材料清单、阶段复盘 | 每天知道做什么，7-21 天有进展 |
| 焦虑型家长 | 担心孩子吃不好、睡不好、发育慢、行为异常 | 查可信百科、看风险信号、理解正常差异、选择计划 | 百科详情、风险提示卡、月龄标签、来源说明 | 把焦虑转为行动，知道何时咨询 |
| 二胎/有经验家长 | 快速确认禁忌、标准、步骤、疫苗儿保节点 | 搜索、看结论、收藏、维护健康节点 | 搜索、短答案卡、收藏、宝宝档案 | 少废话，信息准，节点不漏 |
| 长期使用家长 | 新月龄、计划中断、健康节点临近、系统学习 | 看今日重点、继续计划、查看档案、进入专题 | 今日页、计划页、宝宝档案、专题页 | 有持续陪伴感，复访理由明确 |
| 专家/内容运营 | 新增百科、维护计划、更新指南、审核风险提示 | 维护条目、配置计划、标注月龄、管理来源版本 | CMS、审校后台、标签系统、数据看板 | 内容可追溯，计划可复用 |

## 核心模块

| 模块 | 优先级 | 定位 | 核心分类 |
|---|---|---|---|
| 知识百科 | P0 | 用户遇到问题时快速获得可信答案 | 症状急查、疾病护理、喂养问题、睡眠问题、行为情绪、疫苗体检、日常护理、入园适应 |
| 行动计划 | P0 | 把知识变成可持续执行的步骤 | 辅食、睡眠、戒夜奶、如厕、语言启蒙、行为改善、入园准备、疾病恢复护理 |
| 宝宝档案 | P1 | 轻量个性化和健康节点提醒 | 基础信息、过敏史、当前关注、疫苗记录、儿保体检记录、下次健康节点 |

## 下线模块

| 模块 | 原因 | 保留方式 |
|---|---|---|
| 复杂记录系统 | 高频琐碎记录会让产品变重，不是当前核心价值 | 并入宝宝档案，只保留疫苗和儿保体检 |
| 测评系统 | 独立测评增加复杂度和焦虑感 | 必要判断放进百科条目和计划前置条件 |

## 内容对象模型

| 内容对象 | 作用 | 关键字段 |
|---|---|---|
| 百科条目 | 回答“宝宝这样怎么办” | 标题、摘要、适用月龄、核心结论、先做什么、不要做什么、风险信号、来源、审校人、更新时间 |
| 知识专题 | 聚合一类问题 | 专题名、适用年龄、问题集合、学习顺序、推荐计划 |
| 行动计划 | 把知识变成步骤 | 目标、适用阶段、周期、前置条件、每日任务、材料清单、完成标准、失败处理、复盘节点 |
| 计划任务 | 每天具体做什么 | 所属计划、第几天、任务标题、步骤、预计耗时、完成条件、替代方案 |
| 宝宝档案 | 个性化基础 | 昵称、出生日期、性别、喂养方式、过敏史、当前关注、疫苗次数、儿保体检次数、下次健康节点 |
| 健康节点 | 疫苗和儿保提醒 | 类型、名称、建议月龄、完成状态、完成日期、下次节点、备注 |
| 推荐规则 | 连接内容和用户 | 触发条件、推荐内容、优先级、冷却时间、排除条件 |

## 关键任务流

| 任务流 | 触发 | 路径 | 成功标准 |
|---|---|---|---|
| 查百科 | 出现具体问题或想学习主题 | 搜索/分类 -> 百科条目 -> 结论 -> 风险信号/禁忌 -> 相关行动计划 | 快、准、能落到计划 |
| 开计划 | 想解决阶段问题 | 选目标 -> 看适用条件 -> 开启 7/14/21 天计划 -> 每日任务 -> 阶段复盘 | 任务可执行，节奏稳定 |
| 每日辅助 | 每天打开 App 或收到提醒 | 今日重点 -> 当前计划 -> 相关百科 -> 今日任务 -> 下一步提醒 | 每天知道做什么 |
| 健康节点管理 | 疫苗或儿保临近/完成 | 宝宝档案 -> 确认次数 -> 记录完成节点 -> 下次提醒 -> 注意事项 | 极简记录，节点不漏 |
| 专题学习 | 想系统理解一个问题 | 专题 -> 顺序阅读 -> 收藏重点 -> 开启计划 -> 后续继续 | 内容不散，能转行动 |

## 设计落地原则

1. 首页优先呈现搜索、今日重点和当前行动计划。
2. 百科详情页必须有结论、风险信号、不要做什么、相关计划。
3. 行动计划要像“陪着做”，不是一篇文章。
4. 宝宝档案要轻，只服务适龄推荐和健康节点。
5. 视觉气质要专业可信、温和、少焦虑，不要做成相册或社区。
