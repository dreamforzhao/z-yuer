# 养育地图 App 原型

面向中国大陆 0-5 岁家庭的育儿百科 App 原型。核心方向是专业冷静、可读性高、入口简单、内容持续下钻。

## 当前版本新增

- 孩子建档：出生日期、性别、城市。
- 自动计算月龄，并调整今日任务、阶段卡片、哄睡建议、疫苗儿保节点。
- 新增用品安全页：儿童安全座椅、提篮、尿不湿、餐椅、餐具。
- 新增睡眠哄睡页：按月龄展示睡前流程、夜醒、抱睡转床等建议。
- 扩展百科主题：用品、安全、出行、尿不湿、入园、亲子阅读、父母心理。
- 新增墨刀/产品设计交付稿：`modao-product-handoff.md`。

## 原型范围

- 今日：首页只展示当前阶段最重要的任务、搜索和主题入口。
- 百科：按年龄和主题组织 0-5 岁育儿知识。
- 儿保：接入国家免疫规划、0-6 岁儿童健康管理节点，并预留本地城市规则。
- 用品：用“要不要买、怎么选、怎么用、常见错误、视频链接、品牌维度”组织。
- 详情：内容分成 30 秒、3 分钟、深入学习三层。
- 学习：用专题路径承载图文、短视频、外部文章和对话模板。

## 中国大陆本地化原则

- 疫苗和儿保默认使用国家规则作为基础版本。
- 城市层展示当地疾控、社区卫生服务中心、预约规则和地方补充项目。
- 接种、体检、疾病护理类内容必须保留“以当地门诊和医生判断为准”的提示。
- 第一版不做开放社区，只做精选外部内容和专家审核内容。

## 竞品与书籍参考

- 育学园/崔玉涛体系：专业儿科内容、分龄知识、家长信任感。
- 宝宝树孕育、妈妈网孕育：孕育周期和工具化入口。
- 亲宝宝：成长记录、家庭成员协作。
- 小豆苗：疫苗接种、儿保提醒、本地接种服务。
- 丁香妈妈、年糕妈妈：内容专题、课程化表达、图文视频结合。
- 书籍参考：崔玉涛系列、《美国儿科学会育儿百科》、西尔斯亲密育儿百科、蒙台梭利相关书籍。

## 内容来源建议

- 国家卫生健康委、国家疾控局、地方疾控中心：疫苗和儿保规则。
- WHO：婴幼儿喂养、母乳和辅食原则。
- UNICEF Parenting：家庭养育、营养、情绪和照护。
- CDC Act Early：0-5 岁发育里程碑参考。
- AAP HealthyChildren：儿科健康、睡眠、喂养和安全参考。
- NHS Baby：婴幼儿护理、喂养和疾病护理参考。

## 后续前后端拆分

- 用户和孩子档案服务。
- 月龄计算和推荐服务。
- 内容 CMS 和审核服务。
- 疫苗/儿保日程服务。
- 用品品牌库和参数库。
- 外链视频管理和失效检测。
- 收藏、阅读历史、提醒服务。
- 搜索服务，支持自然语言问题映射到主题。
