# 历史线框说明

本文件原本用于早期墨刀线框交付。当前它只作为历史记录保留。

## 当前请勿沿用的旧方向

- 以成长记录作为首页主线
- 家庭成员协同
- 排便、睡眠、喂养等复杂记录
- 独立测评系统
- 社区或商城主路径

## 当前线框应遵循的新方向

如果需要重新画线框，请按 `parenting-map-fullstack/docs/product-model.md` 执行。

当前首页应优先包含：

1. 宝宝轻档案：月龄、下次儿保/疫苗节点
2. 强搜索：发烧、辅食、夜醒、疫苗等问题
3. 常见问题快速入口
4. 精选回答：先看结论、风险信号、相关计划
5. 继续计划：当前行动计划和下一步任务

底部导航建议：

```text
首页 / 知识库 / 计划 / 我的
```

其中“我的”只承载轻量宝宝档案和健康节点，不承载相册和家庭协同。
