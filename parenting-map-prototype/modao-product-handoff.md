# 养育地图：墨刀/产品设计交付稿

## 1. 推荐设计流程

第一阶段先用墨刀、Figma、即时设计或 Pixso 做信息架构和可点击线框。中国团队协作里，墨刀适合快速评审流程，Figma/即时设计适合后续视觉规范和组件库。建议顺序：

1. 墨刀低保真：确认页面流、内容层级、下钻方式。
2. Figma/即时设计高保真：统一字体、颜色、组件、图标、间距。
3. HTML 交互样机：验证真实滚动、输入、月龄计算、内容切换。
4. 前后端拆分：根据数据对象、接口和后台审核流程开发。

## 2. 页面清单

### P0 页面

- 启动建档页：孩子昵称、出生日期、性别、城市、喂养方式、早产/过敏选填。
- 今日页：首页核心，按月龄生成今日任务、阶段提醒、搜索和主题入口。
- 育儿百科页：按年龄、主题、问题三种方式进入内容。
- 内容详情页：30秒结论、3分钟步骤、深入学习、风险提示、外部链接。
- 疫苗儿保页：国家免疫规划、本地门诊规则、接种记录、儿保节点。
- 用品安全页：儿童安全座椅、提篮、尿不湿、餐椅、床品、洗护、家居安全。
- 学习路径页：母乳、辅食、哄睡、情绪行为、亲子阅读、入园准备等专题。
- 我的页：孩子档案、家庭成员、收藏、阅读历史、提醒设置。

### P1 页面

- 成长记录：身高、体重、头围、牙齿、语言、睡眠。
- 疾病护理风险分级：发烧、腹泻、咳嗽、湿疹、误食、摔伤。
- 品牌对比库：纸尿裤、奶瓶、奶粉、推车、安全座椅等，用维度筛选，不直接带货。
- 视频/外链精选库：运营后台维护链接、来源、适用年龄、审核状态。
- 家庭协作：爸爸、妈妈、老人共用待办和提醒。

## 3. 核心交互

### 建档驱动推荐

用户输入出生日期、性别、城市后，系统计算月龄，并影响：

- 今日 3 件事。
- 首页阶段卡片。
- 睡眠哄睡建议。
- 疫苗和儿保节点。
- 用品安全推荐。
- 搜索结果排序。

### 内容三层结构

每篇内容固定三层，降低学习疲劳：

- 30秒：结论、适用年龄、马上做什么。
- 3分钟：图文步骤、误区、家庭执行方法。
- 深入：权威文章、精选视频、书籍参考、专家解读。

### 用品百科结构

每个用品页固定字段：

- 要不要用：必要、可选、不建议。
- 适用月龄/身高体重。
- 怎么选：安全标准、材质、尺寸、场景。
- 怎么用：安装、清洗、替换、保存。
- 常见错误：危险用法和误区。
- 视频链接：安装或使用演示。
- 品牌库：只做参数和真实反馈维度，不直接承诺“最好”。

## 4. 内容体系

### 年龄轴

- 0-1月：喂养、黄疸、脐带、睡眠安全、提篮。
- 1-3月：奶量、胀气、抬头、疫苗、红屁屁。
- 4-6月：翻身、辅食准备、睡眠节律、误吞风险。
- 7-12月：辅食、爬行、出牙、分离焦虑、安全座椅。
- 1-2岁：走路、语言、挑食、拉拉裤、家居安全。
- 2-3岁：如厕、情绪、规则、绘本、入托准备。
- 3-5岁：入园、社交、表达、运动、屏幕时间、儿童安全教育。

### 主题轴

- 喂养营养：母乳、奶粉、辅食、挑食、过敏、餐具。
- 健康护理：发热、腹泻、便秘、湿疹、咳嗽、误食、摔伤。
- 睡眠哄睡：安全睡眠、睡前流程、夜醒、抱睡、睡眠倒退。
- 发育教育：动作、语言、认知、社交、亲子阅读、游戏。
- 行为情绪：发脾气、打人、咬人、分离焦虑、规则。
- 用品安全：尿不湿、安全座椅、提篮、推车、餐椅、床、洗护。
- 出行家居：乘车、外出包、药箱、插座、尖角、窗户。
- 父母支持：产后情绪、分工、老人沟通、复工准备。

## 5. 竞品和书籍参考

### 竞品参考方向

- 育学园/崔玉涛体系：专业儿科内容、分龄知识、家长信任感。
- 宝宝树孕育、妈妈网孕育：孕育周期和工具化入口。
- 亲宝宝：成长记录、家庭成员协作。
- 小豆苗：疫苗接种、儿保提醒、本地接种服务。
- 丁香妈妈、年糕妈妈：内容专题、课程化表达、图文视频结合。

本产品差异点：不是单一社区、课程或记录工具，而是“分龄百科 + 本地儿保 + 用品安全 + 学习路径 + 家庭执行清单”。

### 书籍参考方向

- 崔玉涛系列：儿科问题、家庭护理、常见育儿误区。
- 《美国儿科学会育儿百科》：医学和发育框架。
- 西尔斯亲密育儿百科：亲子回应和照护视角。
- 蒙台梭利相关书籍：自主探索、家庭环境布置。

书籍只作为框架参考，正式内容需要重新编写、标注来源并做医学/营养/心理/教育分专业审核。

## 7. 后端模块

- 用户和孩子档案服务。
- 月龄计算和推荐服务。
- 内容 CMS 和审核服务。
- 疫苗/儿保日程服务。
- 用品品牌库和参数库。
- 外链视频管理和失效检测。
- 收藏、阅读历史、提醒服务。
- 搜索服务，支持自然语言问题映射到主题。

## 8. 验收标准

- 输入出生日期后，首页月龄和推荐内容立即变化。
- 搜索“安全座椅、尿不湿、哄睡、辅食、疫苗”等词能指向正确页面。
- 所有健康和疫苗内容带风险提示，不替代医生判断。
- 用品页不出现无依据的绝对推荐。
- 墨刀低保真能完整串起建档、今日、百科、详情、儿保、用品、学习 7 个核心流程。
