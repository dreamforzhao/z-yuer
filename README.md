# 育儿百科

面向 0-7 岁孩子家长的 **知识百科 + 行动计划型育儿 App**。

当前项目方向已经明确：产品不是家庭相册、成长记录、复杂测评或社区，而是帮助家长在真实育儿问题里快速获得可信答案，并把答案转成可持续执行的行动计划。

## 当前产品一句话

**查问题，跟计划，陪孩子健康成长。**

## 当前核心

| 模块 | 优先级 | 说明 |
|---|---|---|
| 知识百科 | P0 | 通过搜索和分类快速回答“宝宝这样怎么办”，提供结论、风险信号、不要做什么、相关行动计划 |
| 行动计划 | P0 | 把育儿知识拆成每天能做的一件事，例如辅食、睡眠、戒夜奶、如厕、语言启蒙、入园准备 |
| 宝宝档案 | P1 | 只保留轻量信息：月龄、过敏史、当前关注、疫苗次数、儿保体检次数、下次健康节点 |

## 明确不做

| 不做内容 | 原因 |
|---|---|
| 家庭相册、照片/视频成长记录 | 会把产品带回亲友共享和情感记录，不是当前核心 |
| 排便、睡眠、喂养等复杂记录系统 | 高频琐碎记录会让产品变重 |
| 独立测评系统 | 容易增加复杂度和焦虑感 |
| 妈妈圈、同城圈、社区经验流 | 不是 MVP 主路径 |
| 商城导购 | 不作为主路径 |

## 目录

| 路径 | 作用 |
|---|---|
| `parenting-map-fullstack/` | 当前主项目：本地 Node 服务 + 移动端原型 |
| `parenting-map-fullstack/data/product-model.js` | 结构化产品模型，后续 UI/CMS/推荐逻辑优先读取 |
| `parenting-map-fullstack/docs/product-model.md` | 产品模型说明，后续设计和开发的主要文字依据 |
| `parenting-map-prototype/` | 历史原型资料，仅作参考，不作为当前产品方向来源 |

```

```

## AI 开发约束

后续任何 AI 或开发者接手时，必须先读取：

1. `parenting-map-fullstack/docs/product-model.md`
2. `parenting-map-fullstack/data/product-model.js`

不要根据旧文档、旧页面或竞品惯性把产品改回以下方向：

- 成长记录 App
- 家庭相册 App
- 测评工具 App
- 社区 App
- 母婴商城 App

如果新增页面，优先围绕这 5 条任务流：

1. 查百科
2. 开计划
3. 每日辅助
4. 健康节点管理
5. 专题学习
